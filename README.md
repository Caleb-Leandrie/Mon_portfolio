# Initialisation du depot sur git

## Initialisation de creation de portfolio

```bash
git init
git remote add origin URL_SSH_GIT
```

## Rediger un commit

```
Titre de commit

Description de commit et evolution de projet
```

## Envoyer de commit a distance

```bash
git add .
git commit -m "Titre de commit"
git push origin main
```

## creation d'un nouveau branche

```bash
git checkout -b NOM_DE_BRANCHE
```

Pour les bonnes pratiques , on va appliquer la revue de code.
